# Recipe Card Collection

A clean, responsive HTML and CSS web page showcasing a curated gallery of recipe cards. Designed with modern CSS Grid and Flexbox for seamless responsiveness across mobile, tablet, and desktop screens.

## Features

- **Responsive Grid Layout:** Automatically adjusts the number of columns based on screen size using CSS Grid (`auto-fill` & `minmax`).
- **Flexbox Card Structure:** Keeps card contents aligned consistently regardless of text length.
- **Accessible Navigation:** Uses semantic HTML, logical heading hierarchy, explicit image `alt` attributes, and clear focus-visible styling for keyboard users.
- **Interactive UI:** Smooth hover animations and shadow transitions on interactive elements.

## Tech Stack

- **HTML5**
- **CSS3** (Grid & Flexbox)
